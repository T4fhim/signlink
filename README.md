# SignLnk

Free, open-source, on-device bridge between ASL signers and English speakers.
Raw video and audio never leave the device. Code is Apache-2.0; models and data carry their own
licenses.

Status: **Phase 0 (setup)**. Start with `PROJECT_CONTEXT.md` and `docs/PLAN.md`.

## Quick start

```
pnpm install && uv sync
pnpm dev          # web app
pnpm test         # JS tests
uv run pytest     # Python tests
```

Requires Node 24+, pnpm, and uv.
